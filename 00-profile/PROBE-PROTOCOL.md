# 追问协议（Probe Protocol）

> **通用底座**：不绑定某次 Chat 的固定树；根据学员**本轮回答**动态选下一问。  
> 关联：`MINDSETS.md` §3 考察思维 · `ASSOCIATION-RULES.md` · `STAGE-PORTRAITS.md`（L 档深度上限）  
> Skill：`.cursor/skills/explore-coach`

## 1. 原则

| # | 原则 |
|---|------|
| P1 | **先答后讲** — 未作答不开长篇 |
| P2 | **听答选题** — 下一问由回答内容决定，不背固定路径 |
| P3 | **一次一层** — 每轮最多加压 1～2 层，不连珠炮 |
| P4 | **证据优先** — 追机制、对比、线上怎么证；不听空形容词 |
| P5 | **L 档对齐** — 深度不超过当前阶段画像；不拿 L5 题为难 L3 |
| P6 | **校准优先** — 下一问热点：错题本 > 题源/岗位雷达 > 助手即兴 |
| P7 | **不编造** — 经历题只深挖真实做过的；不会要边界+排查路径 |

## 2. 六类下一问生成器

每轮从学员回答中选 **1 个主生成器**（必要时 +1 个辅助）。**禁止**按固定顺序把六类全问一遍。

### G1 · 主线探测（会不会）

**何时用：** 开场、换题、学员说「不太懂」  
**句式：** 「用 30 秒说清 X 是什么 / 端到端怎么走？」  
**过关信号：** 能串 3 步以上、无硬伤反了概念  

### G2 · 层级下钻（机制）

**何时用：** 主线半对、只会名词  
**句式：** 「你刚提到 A，下一层 B 是谁干的？数据/control 面分别走哪？」  
**过关信号：** 能下钻 1～2 层且不混 Host/Guest/apiserver  

### G3 · 对比施压（真懂 vs 背过）

**何时用：** 回答像背定义、单边描述  
**句式：** 「和 Y 比呢？何时选 A 不选 B？误用代价？」  
**过关信号：** 至少一组对比 + 场景取舍（见 `MINDSETS.md` §1）  

### G4 · 生产可证伪（能不能一起值班）

**何时用：** 理论对、缺线上感  
**句式：** 「线上怎么证明？第一步看啥指标/事件/命令？怎么证伪你的判断？」  
**过关信号：** 有排查分层或指标，不是纯原理  

### G5 · 边界纠偏（硬伤 / 易混）

**何时用：** 概念反了、混层、混名（见 `ASSOCIATION-RULES.md` 触发条）  
**句式：** 「你刚说 …，若 … 则 …？再想想。」→ 学员再答 → 再讲  
**过关信号：** 能自述纠正，不是仅点头  

### G6 · 经历锚定（专长深挖）

**何时用：** 话题能挂故事卡 S1–S6、或学员提生产  
**句式：** 「你线上遇到过吗？STAR 里 Action 具体做了什么？若重来怎么选？」  
**过关信号：** 2～3 层追问不倒；边界诚实  

## 3. 选生成器决策（简表）

```text
学员回答
  ├─ 不会 / 空   → G1 或 G5（探测或给边界）
  ├─ 硬伤/反了   → G5 优先
  ├─ 半对/名词   → G2
  ├─ 对但单边    → G3
  ├─ 对但缺线上  → G4
  ├─ 能挂经历    → G6（且 L 档允许）
  └─ 已过关      → 换题或 G3/G4 加压一层
```

## 4. 与 interview-coach 的分工

| Skill | 场景 |
|-------|------|
| **interview-coach** | FZ 面次、题库、模拟、错题回炉（进度权威） |
| **explore-coach** | 深度探索、纠偏、关联扩展；**同一套 P1–P7 + 六生成器** |

探索专场 **不打乱 FZ** 除非学员 explicit 插队。场末可建议「入库错题 / 写 notes」，不强制改 L3 排期。

## 5. 场末写回（可选）

| 产出 | 写哪 |
|------|------|
| 硬伤/半会 | `review/wrong-book.md` |
