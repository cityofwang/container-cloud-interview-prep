## 2. 命中岗位摘要（画像级）

| 方向 | 典型叫法 | 和你的匹配感 |
|------|----------|--------------|
| 云原生 / K8s 平台研发 | 集群研发、调度/编排/混部、Go | 高（技术深挖 + Go） |
| 容器平台 / PaaS（JDOS/云舰叙事） | 大规模 K8s、混部、大促弹性 | 高（经历可挂钩） |
| 运维开发（Docker/K8s/Linux） | Go + Linux + 网络排障 | 中高（偏运维开发） |
| 纯业务后端 / 算法 | Java 电商、算法岗 | 低（本轮排除细谈） |

城市：公开讨论多为 **北京** base；其他城市需看具体 HC。

## 3. 高频能力词（岗侧）

- Kubernetes 大规模：调度、编排、混部、资源隔离（cgroup/QoS）
- Go（云原生研发常见）/ 或运维开发向的 Linux + 容器网络
- 集群稳定性、排障、oncall；大促弹性与成本
- Informer / 控制器直觉（研发岗）；现象级排障（运维开发岗）
- 加分：etcd/Raft、多集群/边缘——**非 L3 主线必会**

## 4. 待遇 / 工时 / 强度（市场口径，非要约）

### 4.1 薪资

| 口径 | 粗区间 | 备注 |
|------|--------|------|
| T 序列整理文（偏保守） | T3～T6 总包常见约 **40万～60万+**；T7+ 常带股、可上百万量级 | 第三方表；非容器组专属 |
| 校招后端样例 | 约 **21k～33k × 16～20**（科技/零售/物流薪数不同） | **校招**，社招勿直接套 |
| 社招体验样例 | 如 **25k×16** 一类单点 | 样本极少 |

对你（约 6 年容器云向）：谈薪更宜对标 **T4～T6 一带 + 是否核心组/是否带股**，要约时问清归属（科技 vs 零售等）与薪数能否拿满。

### 4.2 上下班

社区常见说法：约 **10:00 到岗**，晚上 **21:00～22:00+**；午休约 1h；周末多数不上班（仍看组）。晚餐/班车/晚到打车常被提到。

### 4.3 强度

- 平日：研发岗普遍反馈「节奏快、强度不小」  
- **618 / 双 11**：基础设施与容器平台相关组压力通常显著抬升  
- 云原生/K8s 岗 JD 常含压力环境、日常运维参与 → **oncall / 故障** 要问清频率
