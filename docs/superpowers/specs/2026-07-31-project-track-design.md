# P 轨：项目学习轨（Project Track）

- 日期：2026-07-31
- 状态：已确认（学员请求落地 MVP）
- 仓库：`container-cloud-interview-prep`

## 1. 目标

在现有面试训练仓内增加 **第七条平行轨** `07-projects/`：

- 沉淀「接触过的 GitHub/工作项目」的 **脱离源码** 学习包
- 与 `notes/`（知识点）、`STORY-CARDS`（经历）分工明确
- **不打乱** FZ1–FZ6 主线；默认周末加练

## 2. 范围

| 做 | 不做 |
|----|------|
| 项目骨架、KNOWLEDGE-INDEX、分章、自测 | 替代通用 notes |
| 挂 KNOWLEDGE-MAP / 故事卡 | 另开平行 wiki |
| `project-learn` Skill + 口令 | 把 P 轨并入 FZ 权重 |
| ONBOARDING 沟通规范 | 依赖 `.understand-anything` 进度 |

## 3. 目录

见 `07-projects/README.md`。

## 4. 口令

| 口令 | 作用 |
|------|------|
| `项目专场 <slug>` | 按项目 INDEX 开练；先答后讲 |
| `项目专场 <slug> <章节>` | 指定章，如 `kata 03-observability` |
| `项目进度` | 列各 PROJECT.md 状态 |
| `新项目 <slug>` | onboarding，见 ONBOARDING.md |
| `项目规划-only` | 只出 INDEX+排期，确认后落仓 |

## 5. 与 interview-coach 关系

- **interview-coach**：FZ + 面次 + 错题（主轨）
- **project-learn**：P 轨深学；学员说 `项目专场` 时优先读本 Skill
- 两 Skill 共存；平日默认仍 FZ
