# 面试教练 Skill + 一键续聊设计

- 日期：2026-07-26
- 状态：已确认（主痛点：唤醒累 → Skill 优先；附带一键续聊脚本）
- 落地：`.cursor/skills/interview-coach/`；`scripts/resume-training.sh`
- 约束：不迁出打分权威；不自动改权重/解锁/大批量改题；提醒类 Automation 本轮不做

## 背景与决策

产品内核保持「Cursor 内教练 + 仓库存档」。主痛点确认为**续聊唤醒摩擦**（每次新 Chat 要贴长模板/想起必读文件），而非忘练提醒或进度看板。

因此本轮只做：

1. **项目 Skill**：把操盘铁律与必读顺序固化，触发词即可开练  
2. **一键续聊脚本**：把开场模板拷到剪贴板，降低「忘记怎么开场」

明确不做：桌面训练台、周末 Automation、只读仪表盘。

## Skill 目标

| 项 | 说明 |
|----|------|
| 名称 | `interview-coach` |
| 位置 | `.cursor/skills/interview-coach/`（随仓库共享） |
| 触发 | 「面试训练」「按操盘规则继续」「周末开练」「我有空…」及同类人话 |
| 体感 | 新对话少贴长模板；仍在 Cursor 里深度追问 |

## Skill 强制流程

每个新对话 / 每次开练：

1. **读** `CONTINUITY.md` 快照；按需读必读列表（口令表、进度板、L3 排期、错题本等）  
2. **先给** 2～4 句：当前阶段、本场建议、等价口令  
3. **执行** 口令或人话映射动作（权威：`COMMANDS.md`）  
4. **场末** 更新快照 / README / 错题或 L3-plan（有变才改）+ 一句话「下次优先」

铁律摘要写进 Skill；细则仍以 `CONTINUITY.md` 与已确认 specs 为准，避免双源漂移。

## 一键续聊脚本

| 项 | 说明 |
|----|------|
| 路径 | `scripts/resume-training.sh` |
| 行为 | 打印开场模板；macOS 上尽量 `pbcopy` 到剪贴板 |
| 参数 | 可选：今天状态字符串（默认「按操盘规则继续」） |
| 不做 | 不自动改仓库、不代开训练内容 |

## 验收

- 新 Chat 说「面试训练」或「按操盘规则继续」时，助手应加载 Skill 并先读 CONTINUITY 再给下一步  
- `bash scripts/resume-training.sh` 输出可粘贴模板；有 `pbcopy` 时提示已复制  
- README / CONTINUITY 点明 Skill 与脚本入口  

## 非目标

- 不新增口令（沿用 `按操盘规则继续`）  
- 不实现周末提醒 Automation  
- 不做进度看板 UI
