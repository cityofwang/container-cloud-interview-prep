# 专注区训练 + 知识点热点（面经驱动）

- 日期：2026-07-27
- 状态：已确认（学员确认：图谱域 + 单场不跨域 C + 热点挂图谱 + 制定排期）
- 落地：`KNOWLEDGE-MAP.md`、`review/roadmap/L3-plan.md`、`CONTINUITY.md` 操盘、`COMMANDS.md`、题源报告
- 约束：不重排题库目录；不自动改八维评估权重；补题须确认；不编造「某厂原题」

## 1. 目标

1. **先答后讲、再面试形态加深**：专场内每点先让学员答 → 再详尽讲解互动 → 同域混场景。  
2. **单场不跨知识大类（模式 C）**：一场只打当前专注区（FZ）。  
3. **面经热点驱动优先级**：高频/必会先啃；场景带相对权重。  
4. **稳步冲 L3**：按 FZ 串行打底，替代「同周强开双轨新课」。

## 2. 知识大类 = 图谱「域」

沿用 `00-profile/KNOWLEDGE-MAP.md` 的「域」，不另造分类树：

| FZ | 域 | 八维 |
|----|----|------|
| FZ1 | 容器/K8s 基础 | C1 |
| FZ2 | 排障与可观测 | C2 |
| FZ3 | Go 基础 | G1 |
| FZ4 | Go 并发 | G2 |
| FZ5 | 混部/cgroup/CSI | C3 |
| FZ6 | 场景过线 / 编码过线 / 表达 | X1/X2 等 |

目录（`01-round1/`、`06-golang/`、`notes/`）**不动**；题与笔记仍按原路径，由 FZ 抽用。

## 3. 单场规则（C）+ 先答后讲

1. 开场声明：**当前 FZ**、建议题序（热点优先）。  
2. 本场题目、笔记、追问不跨另一大域。  
3. 错题回炉优先**同域**。  
4. **单题默认顺序（铁律）**：出题 → **学员先答** → 详尽讲解互动（机制/对比/纠偏/追问）→ 必要时落笔记；**禁止**开场灌输知识点。  
5. `知识点专场`：探测题仍在前；讲解可加长加细，不是「先上课」。

## 4. 热点与场景权重

### 4.1 图谱列

`KNOWLEDGE-MAP` 每点增加：

| 列 | 取值 |
|----|------|
| 热点 | `必会` / `高频` / `常考` / `加分` / `冷门` |
| 场景 | 标签，如 `一面对象` `排障路径` `发布灰度` `调度混部` `Go八股` `云原生Go` `合面综合` |
| L3 | `核心` / `重要` / `可后置` |

同域内专场排序：`必会/高频` ∩ `核心` → `常考` → `加分`；`冷门` 不进周末主战场。

### 4.2 场景相对权重（默认，可被题源校准）

| 场景 | 相对权重 | 说明 |
|------|----------|------|
| 排障路径 | 5 | CrashLoop/OOM/NotReady/Service 不通 |
| 一面对象（Pod/Deploy/Svc/Ingress/探针/配置） | 5 | 一面门槛 |
| Go 并发与排障 | 5 | channel/context/泄漏/GMP |
| Go 基础陷阱 | 4 | error/interface/map |
| 调度混部 / cgroup / CSI | 4 | 岗向加分；学员强项深挖 |
| List-Watch / Informer 直觉 | 3 | L3 要直觉，不强制写 Operator |
| Mesh / 多集群 / 纯算法题海 | 1 | L3 可后置 |

热点来源：`扫题源` 为主、`扫岗位` 为辅。**提议**调表须学员确认后改图谱；**不**因此自动改八维权重。

## 5. 过门

- **域内学→练**：关键点多数达会/半会，不会项有笔记或可口述主线。  
- **一面域另计**：清单会+半会 ≥80% 再约模拟（既有规则）。  
- **开下一 FZ**：当前 FZ 出口达标，或学员明确改期/插队（写进 CONTINUITY）。

## 6. 排期骨架（动态）

详见 `review/roadmap/L3-plan.md`。窗口默认仍 **2026-09-22～2026-11-12**，执行稳可收、受阻可扩。

顺序：FZ1 → FZ2 → FZ3 → FZ4 → FZ5 → FZ6 → 合面短模冲 L3。
